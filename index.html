Create a dashboard access key

This dashboard uses a fine-grained GitHub personal access token to save teams, results and options to the repository hosting this dashboard.

  1. Sign in to GitHub as your repository’s owner, then open Create a fine-grained token.
  2. Give it a name such as Tournament dashboard and choose an expiration date.
  3. Set Resource owner to your account or organisation that owns the repository.
  4. Under Repository access, choose Only select repositories, then select your dashboard repository.
  5. Under Repository permissions, set Contents to Read and write. Leave Metadata at its required read access; no other permissions are needed.
  6. Click Generate token, copy it, paste it into the GitHub token field above, then click Connect organiser.

GitHub only shows the new token once. Keep it private: it can change this repository. Never put it in a URL or commit it to the repository.

If connection or saving fails, check expiry, selected repository and Contents permissions. If you cannot select this repository, contact its owner. GitHub token guide.
